# MTech-AI26058-Project-1-Loan_default_ensemble
🏦 Loan Default Ensemble (v4)

🚀 Advanced Machine Learning-Based Loan Default Prediction System

An intelligent desktop application built with Python, PyQt5, and Scikit-learn that predicts whether a customer is likely to default on a loan using a Stacked Ensemble Learning Model. This project combines the strengths of Random Forest and Gradient Boosting through a Logistic Regression Meta-Learner to deliver highly accurate and reliable predictions for financial institutions.

---

📖 Project Overview

Loan defaults are one of the biggest challenges faced by banks and financial institutions. Incorrect loan approvals can lead to significant financial losses, while rejecting eligible applicants may reduce customer satisfaction and business growth. Traditional single machine learning models often struggle to capture complex borrower behavior and may produce less accurate predictions.

Loan Default Ensemble (v4) addresses this challenge by implementing an advanced Stacked Ensemble Learning approach. Instead of relying on a single algorithm, the application combines multiple machine learning models to improve prediction performance, reduce overfitting, and generate reliable loan default probability scores.

The project features a modern PyQt5 Desktop GUI, enabling users to upload datasets, train models, predict loan default risk, visualize analytics, compare model performance, and export professional reports—all within an intuitive interface.

---

🎯 Project Objectives

- 🏦 Predict the probability of loan default.
- 🤖 Improve prediction accuracy using Ensemble Learning.
- 📊 Generate detailed applicant risk scorecards.
- 📈 Compare the performance of multiple machine learning models.
- ⚡ Provide real-time loan default predictions.
- 📑 Generate downloadable prediction reports.
- 🎨 Offer an interactive and user-friendly desktop interface.

---

❗ Real-World Problem

Banks process thousands of loan applications every day. Approving risky borrowers can lead to financial losses, while rejecting trustworthy applicants may reduce profitability and customer trust.

This project helps solve this challenge by using Artificial Intelligence and Machine Learning to identify risky loan applicants before approval. The system evaluates applicant information, analyzes historical loan data, and predicts the likelihood of default with a confidence score, enabling faster, smarter, and more consistent decision-making.

🧠 Machine Learning Algorithms

🌳 Random Forest Classifier

Used as the first base learner to capture nonlinear relationships, reduce overfitting, and identify important features influencing loan default.

🚀 Gradient Boosting Classifier

Acts as the second base learner by correcting prediction errors iteratively and improving model performance through boosting.

🎯 Logistic Regression Meta-Learner

Combines predictions from both base learners into a final decision using a Stacking Classifier, resulting in improved accuracy and robustness.

7. 🌳 Train Random Forest model
8. 🚀 Train Gradient Boosting model
9. 🧠 Build the Stacked Ensemble model

11. 🎯 Predict loan default probability
